КЫРГЫЗ ФУТБОЛ: приложение (PWA)

1. Разместите все файлы этой папки на любом бесплатном хостинге (адрес должен начинаться с https://):
   - GitHub Pages: создайте репозиторий, загрузите файлы (Add file > Upload files), затем Settings > Pages > Deploy from branch.
   - Cloudflare Pages или Netlify: загрузите папку (проще с компьютера).
   Свой домен не нужен: подойдёт бесплатный адрес вида имя.github.io.

2. Откройте адрес на телефоне.
   iPhone: Safari > Поделиться > На экран «Домой».
   Android: Chrome > меню (три точки) > Установить приложение.

3. Иконка с кыргызским солнцем появится на экране, сайт откроется без адресной строки и будет работать даже без интернета (с последними загруженными данными).

Чтобы обновить данные, замените файл index.html на хостинге.
